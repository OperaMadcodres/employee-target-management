Employee Target Management

Set, track and analyze employee performance targets

Employee Target Management helps organizations create, manage and monitor employee performance targets directly inside Odoo.

Track sales, collections, customer acquisition and other business measurements while comparing target values with actual achievements.

Target Management

Create targets for individual employees and configure target periods, target types and target values. Employees can then be monitored against their assigned targets.

Employee Based Targets

Assign performance targets to individual employees according to your organization's requirements.

Target Periods

Organize targets according to configured target periods and monitor performance within the relevant period.

Approval Workflow

Manage employee targets through a controlled workflow before they become active.

Draft

Prepare and configure the target.

Submitted

Submit the target for approval.

Approved

Approve the target before activation.

Active

Track achievement against the active target.

Completed

Close the target after the target period.

Cancelled

Cancel targets that are no longer required.

Automatic Achievement Calculation

Achievement values can be calculated from Odoo business data according to the configured target type and measurement.

Sales

  • Sales Amount
  • Sales Quantity
  • Sales Count

Collection

  • Collection Amount
  • Collection Count

Customers

  • New Customer Count

Performance Dashboard

Analyze employee performance through an interactive dashboard with filtering and graphical reporting.

Dashboard Filters

  • Period filter
  • Target type filter
  • Status filter

Performance Analysis

  • Target versus achieved chart
  • Employee progress chart
  • Achievement by target type
  • Target status chart
